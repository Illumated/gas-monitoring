# 21. Оборудование

## Заявленный состав

| Компонент | Назначение | Текущий статус |
|---|---|---|
| Датчики давления, 3–5 шт. | Сигналы 4–20 мА; продуктовая шкала `0…10 bar` | Точные модели, паспорта и пороги фиксируются для объекта |
| WB-MAI6 | Преобразование до пяти аналоговых сигналов и опциональной обратной связи, Modbus RTU | Автонастройка подготовлена; требуется аппаратный FAT экземпляра |
| WB-MR3LV/I, опция | Общий удерживаемый сигнал внешней автоматике клапанов | Поддержка подготовлена; до FAT управление отключено |
| USR-DR134 | Modbus TCP ↔ RTU gateway | Модель и адрес заявлены, экспорт настроек отсутствует |
| HDR-30-24 | Питание 24 VDC | Схема распределения и защита не подтверждены |
| ПК/мини-ПК | Node-RED, InfluxDB и dashboard | Целевой Debian-хост не обследован |
| Настенный монитор | Постоянный HMI | Модель и фактическое разрешение не указаны |

## Обязательная фиксация перед подключением

Для каждого устройства записать:

- производитель и точная модель;
- серийный номер;
- firmware;
- параметры питания;
- фото шильдика;
- назначение клемм;
- фактический канал или сетевой адрес.

## Приёмка датчиков и каналов

Каждая токовая петля проверяется независимо:

1. Полярность и целостность при снятом питании.
2. Напряжение питания под нагрузкой.
3. Токовые точки 4, 12 и 20 мА калибратором.
4. Ожидаемые пересчитанные значения около 0, 50 и 100, то есть `0.0`, `5.0` и `10.0 bar` после деления на 10.
5. Реакция на обрыв петли.
6. Соответствие физического газа каналу dashboard.

Без этих доказательств нельзя утверждать метрологическую или эксплуатационную готовность.

Перед этими проверками каждый газовый вход переводится в 4–20 мА и получает шкалу `0…100` по [06 — WB‑MAI6](06-wb-mai6-commissioning.md). Опциональный IN6P настраивается как сухой контакт.
