## Как пользоваться инструкциями

- Команды выполняются из корня репозитория, если рядом не указан другой каталог.
- Блок `Критерий завершения` означает обязательную точку контроля.
- Блок `СТОП` запрещает продолжать, пока причина не устранена.
- Значения в угловых скобках, например `<SHA256>`, заменяются фактическими.
- Windows-команды помечены `powershell`, команды целевого Debian — `bash`.
- Запись регистров WB‑MAI6 допускается только в документе `06` и только после read-only снимка.
