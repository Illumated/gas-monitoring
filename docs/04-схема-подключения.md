# 04. Подключение

## Токовая петля датчика 4–20 мА

```text
+24 VDC → положительный провод датчика
выходной провод датчика → INxP WB-MAI6
iGND соответствующего канала → 0 VDC источника
INxN → не используется для одного датчика на входе P
```

Цвета проводов и число выводов зависят от модели. Перед монтажом схему обязательно сверяют с паспортом конкретного датчика и документацией ревизии WB-MAI6.

Назначение входов: `IN1P` — кислород, `IN2P` — сжатый воздух, `IN3P` — вакуум, `IN4P` — закись азота, `IN5P` — углекислый газ. Подключаются только датчики, выбранные для конкретной установки.

## RS-485

```text
USR-DR134 A ───────── A WB-MAI6
USR-DR134 B ───────── B WB-MAI6
Signal GND ────────── GND по схеме производителей
```

При установленной опции WB‑MR3LV/I он подключается к той же линии RS‑485 с отдельным Unit ID. Заводской профиль использует `66` для WB‑MR3LV/I и `65` для WB‑MAI6; фактические адреса определяются при первом запуске и доступны в сервисном UI. Схема K1 и обратной связи IN6P приведена в [15 — Управление клапанами](15-аварийное-управление-клапанами.md).

Требуется документировать:

- топологию линии;
- длину и тип кабеля;
- экран и точку его подключения;
- оконечивание;
- полярность A/B;
- отсутствие ответвлений, нарушающих выбранную топологию.

## Ограничения безопасности

- `iGND` не является защитным проводником PE.
- Мультиметр в режиме тока подключается только последовательно.
- Запись регистров и перекоммутация выполняются после сохранения исходного состояния.
- Электрическая схема, номиналы защиты и сечения должны быть утверждены до эксплуатации.
