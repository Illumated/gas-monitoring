# 05. Первичная настройка USR‑DR134

Шлюз преобразует запросы Modbus TCP от Node‑RED в Modbus RTU для WB‑MAI6. Настройка выполняется до конфигурирования WB‑MAI6.

## Целевые параметры

| Параметр | Значение проекта |
|---|---|
| Режим Ethernet | Static IPv4 |
| IP / mask | `192.168.50.10 / 255.255.255.0` |
| Gateway / DNS | не задавать в изолированном сегменте |
| Режим работы | Modbus TCP ↔ Modbus RTU, TCP Server |
| TCP port | `502` |
| Serial | `9600 bit/s`, `8 data bits`, `No parity`, `2 stop bits` (`8N2`) |
| WB‑MAI6 address | `65` |

`8N2` соответствует заводским параметрам RS‑485 устройств Wiren Board. Если read-only inventory регистра `112` покажет другое число стоп-битов, сначала устраните расхождение: параметры шлюза и модуля обязаны совпадать.

## Порядок настройки

1. Не подключать шлюз к больничной LAN. Соединить его только с отдельным сервисным ПК.
2. Определить текущий заводской адрес по маркировке, инструкции конкретной аппаратной ревизии или фирменной утилите. Не считать значение по умолчанию универсальным.
3. Открыть web-интерфейс шлюза, сменить заводской пароль администратора и сохранить его в защищённом реестре объекта.
4. Задать параметры из таблицы, применить настройки и перезагрузить шлюз.
5. Подключить Ethernet шлюза к `rinir-modbus`, RS‑485 — к WB‑MAI6: `A` к `A`, `B` к `B`, общий провод согласно проектной схеме.
6. Сохранить снимки всех страниц настроек и зафиксировать модель, серийный номер, аппаратную и программную версии.

Не включайте несколько режимов преобразования или несколько TCP listener одновременно. В штатной цепочке есть один TCP Server на порту `502` и один опрашивающий Modbus-master.

## Проверка с Debian

```bash
ping -c 3 192.168.50.10
nc -vz -w 3 192.168.50.10 502
ip route get 192.168.50.10
```

Маршрут должен идти через `rinir-modbus`, TCP-порт `502` должен открываться. Затем, при включённом WB‑MAI6, прочитать его параметры контейнерным инструментом:

```bash
sudo systemctl stop gas-monitoring.service
sudo install -d -m 0755 /var/lib/rinir-factory/commissioning
sudo docker run --rm --network host \
  --volume /var/lib/rinir-factory/commissioning:/evidence \
  --entrypoint node gas-monitoring-node-red:0.1.0 \
  /usr/src/node-red/tools/hardware-fat.mjs \
  --inventory --host 192.168.50.10 --port 502 --unit 65 \
  --inputs IN1P,IN2P,IN3P --operator "<исполнитель>" \
  --device-serial "<серийный номер>" --evidence /evidence
```

В evidence ожидаются `baudRateDividedBy100=96`, `parity=0`, `stopBits=2`, `slaveId=65`. После проверки приложение пока не запускать: следующим этапом выполняется [06 — настройка WB‑MAI6](06-wb-mai6-commissioning.md).

## Критерий завершения

- `192.168.50.10` доступен только через Modbus LAN;
- `502/tcp` открыт;
- inventory успешно читает WB‑MAI6 с Unit ID `65`;
- фактические `9600 8N2` подтверждены чтением регистров;
- конфигурация и реквизиты шлюза сохранены в защищённом комплекте объекта.

Если TCP доступен, но Modbus не отвечает, не переходить к записи регистров: проверить питание WB‑MAI6, A/B, общий провод, Unit ID и полное совпадение serial-параметров.
