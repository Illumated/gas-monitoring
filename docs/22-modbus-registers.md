# 22. Modbus и карта регистров

## Целевой профиль

| Параметр | Значение | Статус |
|---|---|---|
| Gateway | `192.168.50.10:502` | Заявлено |
| Transport | Modbus TCP → RTU | Заявлено |
| WB‑MAI6 Unit ID | Автообнаружение; заводской профиль `65` | Подтверждается inventory |
| Serial | `115200 8N2` | Должно быть подтверждено inventory |
| Input type | 4–20 мА, code `4866` | Подтверждено документацией |
| External scale | `0…100` | Проектное решение для датчиков 0–10 bar |

## Каналы

Полная карта `IN1P…IN6P` и `IN1N…IN6N` приведена в [06 — WB‑MAI6](06-wb-mai6-commissioning.md). Продуктовый flow использует следующую фиксированную привязку:

| Газ | Вход | Type holding u16 | Scale low i16 | Scale high i16 | Basic current input i32 |
|---|---|---:|---:|---:|---:|
| O₂ | IN1P | 5120 | 5128 | 5130 | 5376–5377 |
| AIR | IN2P | 9216 | 9224 | 9226 | 9472–9473 |
| VAC | IN3P | 13312 | 13320 | 13322 | 13568–13569 |
| N₂O | IN4P | 17408 | 17416 | 17418 | 17664–17665 |
| CO₂ | IN5P | 21504 | 21512 | 21514 | 21760–21761 |
| Клапаны, обратная связь | IN6P | 25600 | — | — | 25860 |

Dashboard и Modbus-очередь используют только явно отмеченные в сервисном UI газовые входы. Допустимо от трёх до пяти любых каналов из карты выше; неактивные входы не опрашиваются. IN6P зарезервирован для обратной связи клапанов и настраивается как сухой контакт с кодом `5632`.

Пересчёт выполняется из базового тока: `pressure_bar = max(0, (current_mA - 4) × 0.625)`.

Регистры границ — отдельные знаковые 16-битные значения. Соседние адреса принадлежат входам `INxN`; это не слова одного `i32`.

Целевой профиль обеих сторон — `115200 8N2`. При пусконаладке регистры WB‑MAI6 `110…113` читаются до любого изменения, а web-настройки USR‑DR134 сохраняются снимками. Переключение выполняется согласованно на WB-устройствах и USR-DR134; изменение только одной стороны разрывает связь.

## Специальные значения

- Базовое значение имеет формат signed 32-bit и единицу `nA`.
- Ток ниже `3.5 мА`, а также коды `2147483647` и `-2147483648` означают `НЕТ ДАННЫХ`.
- Диапазон `3.5…4 мА` отображается как `0.0 bar`; диапазон `4…20 мА` линейно пересчитывается в `0.0…10.0 bar`.
- Отсутствующее, нечисловое или устаревшее значение должно приводить к `nodata`.
- Все активные входы одного полного цикла публикуются единым снимком и имеют одинаковое время измерения; промежуточные ответы не должны расходиться между страницами Dashboard и управляющей логикой.

## Расхождения исходного flow

Исходный `flows/flows.json` использует direct serial `/dev/ttyS0`, `9600 8N2`, Unit ID `1`, `HoldingRegister` и деление на `100`. Это состояние сохранено первым коммитом и не считается целевой конфигурацией без отдельного подтверждения владельца.

## Правило изменения оборудования

Перед любой записью:

1. Прочитать текущие значения.
2. Сохранить вывод команды и дату.
3. Записать только согласованный регистр.
4. Прочитать значение обратно.
5. Проверить сохранение после power cycle.

Полная процедура и проверенный скрипт: [06 — WB‑MAI6](06-wb-mai6-commissioning.md).
