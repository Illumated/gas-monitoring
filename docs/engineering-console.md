# Сервисная консоль

Адрес: `http://127.0.0.1:1880/dashboard/engineering`.

## Диагностика

Без разблокировки отображаются:

- возраст последнего измерения O₂, AIR и N₂O;
- свежесть каждого Modbus-канала;
- последняя успешная запись InfluxDB;
- состояние и последняя доставка MAX;
- последняя runtime-ошибка.

Это инженерный экран. Врачебный экран мониторинга остаётся неизменным и не содержит управляющих элементов.

## Изменение порогов

1. В `.env` задать уникальный `SERVICE_ACCESS_CODE`.
2. Открыть сервисную страницу и ввести код.
3. Для каждого газа задать четыре упорядоченные границы:

   ```text
   0 ≤ красная→жёлтая ≤ жёлтая→зелёная
     < зелёная→жёлтая ≤ жёлтая→красная
     < максимум шкалы
   ```

4. Указать исполнителя.
5. Нажать «Проверить и сохранить».
6. Проверить новые границы на monitoring и history.
7. Проверить событие `НАСТРОЙКИ → ИЗМЕНЕНЫ` в `/dashboard/events`.

Настройки применяются со следующего измерения и сохраняются в persistent Node-RED context. Неверный порядок отклоняется целиком; частичное сохранение невозможно.

## Возврат к значениям `.env`

В текущей версии автоматический сброс через UI намеренно отсутствует. Для возврата ввести значения из утверждённого `.env` вручную и сохранить с указанием исполнителя. Это оставляет проверяемый след в журнале.
