# 15. Аварийное управление клапанами

Функция опциональна и по умолчанию отключена. Она не заменяет проект автоматики клапанов, независимую защиту или ручное управление.

## Как это работает для пользователя

Система постоянно следит за давлением выбранных медицинских газов. Для управления можно выбрать любой из пяти каналов:

| Газ | Канал WB‑MAI6 |
|---|---|
| Кислород | `IN1P` |
| Медицинский воздух | `IN2P` |
| Вакуум | `IN3P` |
| Закись азота | `IN4P` |
| Углекислый газ | `IN5P` |

Если давление хотя бы одного выбранного газа переходит в красную аварийную зону, система после заданной задержки переводит общий выход в аварийное состояние. Этот выход не питает клапаны напрямую: он передаёт внешней клапанной автоматике удерживаемый сигнал «авария». После нормализации всех причин система выдерживает задержку возврата и снимает сигнал.

На экране отдельно показывается состояние клапанной автоматики. Если отправленная команда не совпала с полученной обратной связью, оператор увидит неисправность, а событие попадёт в журнал и, при включённых уведомлениях, в MAX.

В сервисном разделе для каждого действующего канала есть отдельный флажок с названием газа и номером входа. При первой настройке управляющими выбраны все действующие газы. Если позднее включён дополнительный датчик, его участие в управлении нужно подтвердить отдельным флажком.

Выбор газа означает выбор причины одного общего аварийного сигнала. Это не пять отдельных релейных выходов: в принятой схеме приложение использует один выход `K1`.

## Техническое описание принятой схемы

| Устройство | Параметр проекта |
|---|---|
| WB‑MR3LV/I | Modbus RTU, адрес `66`, `115200 8N2` |
| K1 | общий удерживаемый контакт, Modbus Coil `0` |
| K2, K3 | резерв, приложение ими не управляет |
| WB‑MAI6 IN6P | сухой контакт `5632`, Input Register `25860` |
| Обратная связь | `1` — штатный режим, `0` — аварийный режим |

WB‑MR3LV/I имеет переключающий контакт SPDT. Какую пару `COM/NO/NC` использовать, определяет утверждённая электрическая схема: при потере питания и связи клапанная автоматика должна переходить в заранее определённое безопасное состояние. Node‑RED не коммутирует катушку клапана напрямую — K1 выдаёт только согласованный сигнал внешней автоматике.

## Режимы приложения

- `Оборудование не установлено`: IN6P и WB‑MR3LV/I не влияют на экран.
- `Только контроль`: приложение читает IN6P, показывает и журналирует штатный/аварийный режим, но Coil 0 не пишет.
- `Автоматическое управление`: выбранные аварии газов формируют удерживаемую команду K1; возврат автоматический после снятия всех причин и выдержки задержки.

В сервисном UI задаются режим, список управляющих газов (`Кислород — IN1P` … `Углекислый газ — IN5P`), реакция на `НЕТ ДАННЫХ`, задержки срабатывания и возврата, таймаут обратной связи. Несовпадение команды и IN6P отображается как отдельная неисправность и отправляется в MAX.

## Пусконаладка

1. Зафиксировать адрес, прошивку и исходные настройки WB‑MR3LV/I.
2. Настроить уникальный адрес `66`; WB‑MAI6 остаётся `65`.
3. Проверить чтение/запись Coil `0` только на отключённой от исполнительного механизма цепи.
4. Проверить, что замыкание обратной связи даёт `25860 = 1`, размыкание — `25860 = 0`.
5. Подключить внешнюю автоматику по утверждённой схеме и проверить штатное состояние при старте, потере питания, обрыве RS‑485 и перезапуске Node‑RED.
6. Сначала включить `Только контроль`. Автоматический режим разрешить лишь после полного FAT с представителем, ответственным за клапанную автоматику.

Официальные карты: [WB‑MR3LV/I](https://wiki.wirenboard.com/wiki/WB-MR3LV/I%28K%29_and_WB-MR6LV/I%28K%29_Modbus_Relay_Modules), [релейные регистры](https://wiki.wirenboard.com/wiki/Relay_Module_Modbus_Management), [WB‑MAI6](https://wiki.wirenboard.com/wiki/WB-MAI6_Modbus_Registers).

## Критерий завершения

Подписанный FAT подтверждает команду K1, обратную связь IN6P, безопасное состояние при отказах и отсутствие непреднамеренного управления K2/K3.
