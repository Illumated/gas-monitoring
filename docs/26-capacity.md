# 26. Ёмкость хранения

## Расчётная нагрузка

При трёх каналах и одном измерении каждого канала в секунду:

```text
3 × 86 400 × 365 = 94 608 000 точек в год
```

Расчёт воспроизводится командой:

```powershell
npm run capacity
```

Сценарии планирования сжатых данных:

| Расчётный размер точки | Данные за 365 суток |
|---:|---:|
| 16 bytes | 1,41 GiB |
| 32 bytes | 2,82 GiB |
| 64 bytes | 5,64 GiB |

Это расчётные сценарии, а не гарантия InfluxDB. Дополнительно используются WAL, индексы, временные файлы compaction, журнал событий и файловая система.

## Требование к диску

- не менее `20 GiB` для volume `influxdb-data`;
- не менее `20 GiB` в отдельном хранилище резервных копий;
- предупреждение при 70% заполнения;
- критическое событие при 85%;
- повторный расчёт по фактическому росту данных после не менее семи суток эксплуатации.

Retention `8760h` ограничивает историю 365 сутками, но не заменяет контроль свободного места.
