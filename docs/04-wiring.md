# 04. Подключение

## Заявленная токовая петля PT-506

```text
+24 VDC → красный провод PT-506
чёрный провод PT-506 → INxP WB-MAI6
iGND соответствующего канала → 0 VDC источника
INxN → не используется для одного датчика на входе P
```

Схема является проектной исходной точкой. Перед монтажом её необходимо сверить с паспортом конкретного PT-506 и документацией ревизии WB-MAI6.

## RS-485

```text
USR-DR134 A ───────── A WB-MAI6
USR-DR134 B ───────── B WB-MAI6
Signal GND ────────── GND по схеме производителей
```

Требуется документировать:

- топологию линии;
- длину и тип кабеля;
- экран и точку его подключения;
- оконечивание;
- полярность A/B;
- отсутствие ответвлений, нарушающих выбранную топологию.

## Ограничения безопасности

- `iGND` не является защитным проводником PE.
- Мультиметр в режиме тока подключается только последовательно.
- Запись регистров и перекоммутация выполняются после сохранения исходного состояния.
- Электрическая схема, номиналы защиты и сечения должны быть утверждены до эксплуатации.
